## Key Insights & Results

The Power BI dashboard and SQL analytics revealed several important economic trends across the selected countries.

### GDP Insights

- The United States maintained the highest GDP among analyzed countries.
- China and India demonstrated the fastest long-term GDP growth trends.
- Forecasting models predicted continued GDP expansion for emerging economies.

### Inflation Insights

- Inflation trends showed significant volatility during global economic disruptions.
- Developing economies experienced higher average inflation compared to developed nations.

### Population Insights

- India recorded the highest projected population growth.
- Japan and Germany showed relatively slower population growth trends.

### Forecasting Results

- Linear Regression forecasting projected continued GDP growth for all analyzed countries.
- Forecast outputs were integrated into SQL analytics and Power BI reporting workflows.

### SQL Analytics Results

Advanced SQL queries enabled:

- GDP ranking analysis
- Inflation comparison reporting
- Forecast growth analysis
- Window-function-based country ranking
- Star-schema-based analytical joins

### Dashboard Capabilities

The Power BI dashboard provides:

- Dynamic country filtering
- KPI tracking
- Economic trend visualization
- Forecast comparisons
- Role-based secure access using RLS
